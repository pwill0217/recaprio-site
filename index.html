A few useful answers

Before you hit record.

Still curious? Talk to us.

Which computers does Recaprio support?

The desktop installer targets Windows. The project also supports a manual macOS setup; a consumer Mac installer is not currently advertised.

Does it work offline?

Narration, transcription and rendering run locally. The Windows installer is designed to include the required models. Pro license activation and validation require an internet connection, with a 14-day offline grace period after a successful check.

Can I use my own footage?

Yes. Add images and clips in script mode, or open a longer video in clip mode. Use content you own or have permission to use.

Does it find highlights automatically?

Yes. "Find clips for me" suggests the strongest moments and says why it picked each one, and Auto-clip renders the best ones in one click. You can always review and adjust before exporting. Automatic face tracking is planned.
