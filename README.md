# Recaprio landing page

Static marketing website for Recaprio. Open `index.html` in a browser; no build or dependencies are required.

## Hosting on GitHub Pages

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/ (root)**, and click **Save**. The site will be published at https://pwill0217.github.io/recaprio-site/ after the Pages deployment finishes. Future changes to main redeploy automatically.

## Contact and early access

Support: recapriosupport@gmail.com.

The early-access form validates the visitor's email and opens a prefilled mailto draft. Visitors must send the draft to complete their request. No submissions are stored by this static site. A hosted form endpoint is needed for automatic signups.

## Product availability

The site describes the local script and clipping workflows and the existing Free/Pro distinction. Pro pricing, checkout, and public installer links are intentionally not invented. Add those when the business is ready to launch.

The hero illustration is labeled as illustrative and is not an exported product demo.
